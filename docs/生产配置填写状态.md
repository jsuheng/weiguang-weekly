# 生产配置填写清单

部署前由运维确认：

- [ ] `.env` 已从 `.env.example` 创建；
- [ ] `APP_BASE_URL` 已填写公司内网域名；
- [ ] `PASSWORD_PEPPER`、`CRON_SECRET` 均为至少 32 位随机值；
- [ ] PostgreSQL 数据库名、用户、密码与 `DATABASE_URL` 一致；
- [ ] `FILE_STORAGE_DIR=/data/files`；
- [ ] `FILE_STORAGE_HOST_PATH=/data/weiguang/files`；
- [ ] `APP_IMAGE` 指向当前项目 Harbor 镜像；
- [ ] `/data/weiguang/postgres`、`/data/weiguang/files`、`/data/weiguang/backups` 已创建；
- [ ] `/data/weiguang/files` 的属主为 `1000:1000`，应用容器可写；
- [ ] Caddy、内网 DNS 与防火墙已配置；
- [ ] GitLab 的 Harbor、SSH 私钥和 `SSH_KNOWN_HOSTS` 已配置；
- [ ] 每日备份 Cron 已配置；
- [ ] 首个 Leader 已通过脚本初始化并完成首次改密。
