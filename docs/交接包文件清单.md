# 周报系统内网部署交接包清单

## 交付范围

本交接包包含可构建的完整源码和公司内网部署所需文件：

- Next.js 应用源码、锁定依赖文件和生产构建配置；
- PostgreSQL 数据结构、迁移文件和迁移执行器；
- 公司服务器文件目录存储接口；
- Dockerfile、Docker Compose 和 GitLab CI 配置；
- 生产环境 `.env`；
- 部署前检查、备份、恢复、首个 Leader 初始化脚本；
- 运维部署手册、服务器文件存储说明、生产配置核对清单和测试样例。

交接包不包含：

- `node_modules`、`.next` 等可重新生成的构建缓存；
- 本地 PGlite 演示数据库和本地上传文件；
- `.env.local` 本地预览配置；
- 本地 Git 历史和旧交接压缩包。

## 运维首次部署入口

1. 阅读 `docs/运维部署交接手册.md`。
2. 将项目解压到 `/data/gitlabci/weiguang-weekly`。
3. 确认 `.env` 权限为 `600`，并复核内网地址和密钥。
4. 执行：

```bash
mkdir -p /data/weiguang/postgres /data/weiguang/backups
install -d -m 0750 -o 1000 -g 1000 /data/weiguang/files
bash scripts/preflight.sh
docker compose --env-file .env up -d
curl -fsS http://127.0.0.1:7019/api/health
bash scripts/bootstrap-leader.sh leader "Leader姓名" "内容增长组"
```

5. 完成 Leader 首次改密、实习生创建、数据导入、容器重启持久化及备份恢复验收。

## 完整性校验

将压缩包和同名 `.sha256` 文件放在同一目录，执行：

```bash
shasum -a 256 -c weiguang-weekly-intranet-handoff-*.tar.gz.sha256
```

输出 `OK` 后再解压部署。
